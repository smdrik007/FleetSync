# FleetSync mobile (Android)

Expo SDK 57 app for drivers (trip console, background GPS) and passengers (live map). It talks to `../backend`.

Needs JDK 17, the Android SDK (Platform 36) and `ANDROID_HOME`. Expo Go is not supported: background location needs a development build.

```bash
cp .env.example .env            # EXPO_PUBLIC_API_URL
adb reverse tcp:3000 tcp:3000   # phone/emulator reaches the backend as localhost:3000
npm install
npx expo run:android            # builds the dev client, installs it, starts Metro
```

`android/` is generated by prebuild and gitignored. Change native config in `app.json`, never in `android/`.

## Using the app away from your PC

The APK talks to `EXPO_PUBLIC_API_URL`, which is baked in at build time. The login screen shows the current
server at the bottom ("Server: ... Change") and lets you point it at another HTTPS address.

1. Start the backend: `cd backend && npm start`
2. Open a public tunnel: `powershell -File backend/scripts/tunnel.ps1`, and copy the `https://....trycloudflare.com` address it prints.
3. In the app: login screen, Server, Change, paste the address, Save.

The address changes every time the tunnel restarts. The backend and tunnel must stay running on the PC.
Quick tunnels are for testing: for a stable address, deploy the backend to a host and rebuild with
`EXPO_PUBLIC_API_URL=https://your-host`. Release builds refuse plain `http://` addresses.
